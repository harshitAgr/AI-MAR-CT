 1. **Deep Learning-Based Metal Artifact Reduction in CT for Total Knee Arthroplasty (KMAR-Net)** <img src="https://img.shields.io/badge/Supervised-blue.svg" alt="Supervised"> \
*J. Lee, H.-D. Chae, H. Cho, J. M. Kim, S. H. Hong, J.-Y. Choi, H. J. Yoo, S.-J. Ye* \
**Summary** \
KMAR-Net is a supervised, image-domain CNN designed specifically for post-operative knee CT after total knee arthroplasty (TKA), where large high-atomic-number femoral and tibial implants produce severe streak artifacts that are difficult for generic MAR methods to handle. Unlike dual-domain networks, KMAR-Net does not require projection data at inference, does not use an explicit metal segmentation step, and does not rely on a-priori knowledge of implant shape — the metal-corrupted axial slice is fed directly to the network and the artifact-reduced slice is produced end-to-end, which sidesteps the secondary-artifact problem caused by segmentation errors in projection-completion pipelines. Training data is generated via a sinogram-handling simulation pipeline: axial knee CT scans from 50 patients without any metallic implant are used as artifact-free references, simplified virtual metal shapes mimicking commonly used TKA components (distal femur, proximal tibia, long-stem variants) are manually designed with randomised size, orientation and position, and each metal-inserted image is forward-projected, metal-trace-replaced, and back-projected to obtain a paired artifact/clean slice — 500 pairs per patient, 25,000 pairs in total, split 15,000 / 5,000 / 5,000 for training / validation / simulated-test. A 44-patient clinical test set with prior TKA (18 unilateral, 26 bilateral) is used for the real-world evaluation, and a separate CTDI-phantom experiment (stainless-steel and aluminium rods, varying count, tube voltage 100/120 kVp, slice thickness 1/2 mm, bone and standard kernels) with 474 simulated pairs (330 / 72 / 72) plus 80 real phantom images is used to check feasibility under controlled conditions. The network is implemented in PyTorch 1.1.0; architectural specifics and training hyper-parameters (loss, optimiser, learning rate, inference time, exact GPU model) are deferred to the paper's supplementary material, with source code released at github.com/ljm861/KMAR-Net. On the simulated test set KMAR-Net reaches Pearson correlation coefficient (PCC) 0.995, PSNR 41.49 dB and SSIM 0.996 against the artifact-free reference. On the 44-patient clinical test set the area of dark streak artifacts (≤ −200 HU pixels within the knee outline) drops from 2,165.2±576.5 mm² (Non-MAR) and 1,554.6±566.3 mm² (O-MAR, the commercial projection-based orthopaedic MAR baseline) to 100.6±94.5 mm² (KMAR-Net); mean attenuation within the streaks rises from −724.9±71.8 HU (Non-MAR) / −424.2±59.4 HU (O-MAR) to −247.7±28.0 HU (KMAR-Net), and the intra-streak SD collapses from 295.7±11.7 / 218.8±35.4 HU to 68.5±50.3 HU — all differences significant at p < 0.001. On the phantom, KMAR-Net (PCC 0.994 / PSNR 39.64 dB / SSIM 0.988; mean HU 117.3 / SD 19.2) is the closest to the metal-free reference (mean HU 118.7 / SD 19.9) and clearly beats O-MAR (0.985 / 35.85 / 0.938 ; 108.2 HU / 49.1 SD) and Non-MAR (0.928 / 31.27 / 0.895 ; 94.2 HU / 182.9 SD). Two musculoskeletal radiologists graded KMAR-Net superior to O-MAR for overall artifact level and soft-tissue depiction on all 44 clinical cases (5-point Likert, all P < 0.001), with bone-conspicuity superiority significant for the less-experienced reader (P < 0.001) but not the 6-year reader (P = 0.080); pseudocement artifacts dropped from 37/44 (84%) in O-MAR to 16/44 (36%) in KMAR-Net (P < 0.001). The authors note several limitations: (1) a newly introduced band-like soft-tissue blurring appears in 27/44 (61%) of KMAR-Net cases (absent from O-MAR), concentrated where the original streak burden was most severe, and cannot be explained analytically — a fundamental drawback of data-driven MAR; (2) the sinogram-handling simulation does not fully reproduce real-world physics (cone-beam effects, tube-current modulation, scatter, non-linear partial volume), so there is a residual simulated-to-real domain gap; (3) the 44-case clinical cohort is small, female-dominant, and restricted to four implant families (Vanguard, Attune, LPS-Flex, LCCK), limiting generalizability across sex, anatomy and implant design; (4) the only comparison is against commercial O-MAR — no head-to-head with dual-energy, hybrid, transformer, or diffusion-based DL MAR methods. \
Scientific Reports, 2025. [[doi](https://doi.org/10.1038/s41598-025-21012-7)] [![Open Access](https://img.shields.io/badge/Open%20Access-brightgreen.svg)](https://www.nature.com/articles/s41598-025-21012-7) [![Code](https://img.shields.io/badge/Code-purple.svg)](https://github.com/ljm861/KMAR-Net)

 1. **FIND-Net: Fourier-Integrated Network with Dictionary Kernels for Metal Artifact Reduction** <img src="https://img.shields.io/badge/Supervised-blue.svg" alt="Supervised"> \
*F. Tasharofi, F. Fan, M. Qahqaie, M. Thies, A. Maier* \
**Summary** \
FIND-Net is a supervised, image-domain deep-unfolding MAR network that extends DICDNet's convolutional-dictionary model with joint spatial / frequency-domain processing to address CNNs' limited receptive fields. The underlying physical model decomposes a metal-corrupted CT image Y into an artifact-free component X and an artifact term A = Σₙ Kₙ⊗Mₙ, where Kₙ are learnable dictionary kernels that encode metal-artifact patterns and Mₙ are their feature maps; the masked reconstruction objective min_{M,X} ‖I⊙(Y−X−A)‖²_F + λ₁P₁(M) + λ₂P₂(X) is unrolled into 10 iterative stages, each containing an M-Net (updates M via a proximal step) and an X-Net (updates X via a proximal step), both implemented as ResNets whose standard 3×3 convolutions are replaced by FE-ResBlocks (Frequency-Enhanced ResBlocks) built on GFFC — a modified Fast Fourier Convolution that splits channels into a Local Branch for spatial convolutions and a Global Branch that applies FFT → trainable Gaussian filter Gσ,c(u,v) = exp(−((D²−c²)/(D·σ+ε))²) → 1×1 conv → IFFT, with learnable σ and c giving per-layer adaptive frequency selection. The Global-Branch channel fraction α increases across stages from 0.0 to 0.8, so early stages emphasise local spatial refinement while later stages emphasise global frequency-domain artifact suppression; X⁽⁰⁾ is initialised with linear interpolation (LI). Training uses a multi-term stage-wise loss L = Σₛ ωₛ‖I⊙(X−X⁽ˢ⁾)‖²_F + γ₁Σₛ ωₛ‖I⊙(X−X⁽ˢ⁾)‖₁ + γ₂Σₛ ωₛ‖I⊙(Y−X−A⁽ˢ⁾)‖₁, combining a Frobenius reconstruction term with L1 sparsity and artifact-consistency terms. The network is trained on the AAPM CT-MAR Grand Challenge dataset (XCIST-simulated from NIH DeepLesion body scans and UCLH Stroke EIT head scans, with realistic quantum noise / beam hardening / scatter) at 512×512: 5,500 training cases (1,300 head + 4,200 body), 700 validation and 700 test cases, plus a 29-case real-world evaluation set without ground truth. Implementation is in PyTorch on an NVIDIA A100 (80 GB HBM2) with AdamW (β₁=0.9, β₂=0.999), LR 1×10⁻⁴, weight decay 1×10⁻⁵, linear warm-up + cosine annealing, batch size 6, up to 200 epochs with early stopping. Across metal sizes FIND-Net reports average MAE/SSIM/PSNR of 17.9 / 0.952 / 42.8 dB, versus LI (26.6 / 0.913 / 38.9), DICDNet (18.3 / 0.951 / 42.4), OSCNet (18.8 / 0.948 / 41.7), OSCNet+ (18.8 / 0.948 / 42.0), and the FIND-Net (No-GF) ablation (18.2 / 0.951 / 42.5); the relative improvements over the DICDNet baseline — −3.07% MAE, +0.18% SSIM, +0.90% PSNR — are statistically significant at the 95% CI level. On seven artifact-free anatomical patches (where an ideal MAR should not change the image), FIND-Net achieves the best preservation (MAE 0.005 / SSIM 0.97 / PSNR 43.23 dB) vs. DICDNet-level baselines (~MAE 0.007 / SSIM 0.94 / PSNR 40.4 dB). Computational complexity drops ~16% (334.45 → 279.55 GFLOPs) via FFT-based operations, but per-image inference time grows from 0.15 s (DICDNet) to 1.07 s because of the frequency-domain transforms — the authors flag this latency overhead as the method's main practical limitation; they additionally observe that OSCNet / OSCNet+ underperform DICDNet on this benchmark, suggesting their rotational-symmetry encoding generalises less well than FIND-Net's frequency-adaptive formulation. \
[[arXiv](https://arxiv.org/abs/2508.10617)] MICCAI, 2025. [[doi](https://doi.org/10.1007/978-3-032-05169-1_19)] [![Open Access](https://img.shields.io/badge/Open%20Access-brightgreen.svg)](https://papers.miccai.org/miccai-2025/paper/1842_paper.pdf) [![Code](https://img.shields.io/badge/Code-purple.svg)](https://github.com/Farid-Tasharofi/FIND-Net)

 1. **Balancing Efficiency and Restoration: Lightweight Mamba-Based Model for CT Metal Artifact Reduction** <img src="https://img.shields.io/badge/Supervised-blue.svg" alt="Supervised"> \
*W. Qu, S. Liang, X. Li, C. Pan, A. Yan, A. Elazab, S. Niu, D. Zeng, X. Wan, C. Wang* \
**Summary** \
MARMamba is a lightweight, image-domain-only supervised MAR network that replaces standard Transformer attention with state-space (Mamba) blocks inside a streamlined U-Net, aiming for a favourable trade-off between artifact suppression, parameter count, and memory. The backbone takes a B×1×H×W metal-corrupted CT image, lifts it to D=12 channels via a 3×3 convolution, and routes features through a symmetric encoder-decoder with Multi-Scale Mamba (MS-Mamba) blocks configured sequentially as [1, 2, 2, 4, 2, 2, 1, 1] across the down/up stages. Each MS-Mamba is built from two key components: (i) a Flip Mamba Block (FMB) that runs three parallel Mamba instances on the original, horizontally-flipped, and vertically-flipped feature maps to pool streak information from multiple directions that single-pass SSM scans would otherwise miss; and (ii) an Average Maximum Feed-Forward Network (AMFN) that fuses max-pooled (dominant artifact response) and average-pooled (global structure) pathways before the residual merge. Because MARMamba operates only on images, it needs no sinogram access at inference—simplifying deployment on post-processing pipelines. It is trained supervised on SynDeepLesion with 1,000 paired metal-corrupted/metal-free training images and 200 test pairs, using a progressive multi-resolution schedule: 256×256 (batch 8, 100k iterations) → 336×336 (batch 4, 200k iterations) → 416×416 (batch 2, 20k iterations), optimised with Adam + CosineAnnealingLR. The loss is α·Pseudo-Huber (α=0.8) + β·LPIPS perceptual (β=0.2) with a weighting coefficient c=0.03; total training takes 27.31 hours on a single NVIDIA RTX 3090. On the SynDeepLesion test set MARMamba reports, by artifact size, PSNR / SSIM / RMSE of 47.60±1.65 dB / 0.9943±0.0014 / 1.26±0.23 (large), 47.90±3.20 dB / 0.9948±0.0014 / 1.28±0.45 (medium), 50.91±1.33 dB (small) and 52.03±0.95 dB (tiny), outperforming InDuDoNet, OSCNet, MEPNet, DuDoDp and MARformer; the Transformer-based MARPVT is competitive (46.62 dB PSNR on large) with slightly faster inference. MARMamba has 0.59M parameters—the smallest among the compared baselines—and runs at 0.0393±0.0008 s per 416×416 image on the RTX 3090. The authors note two main limitations: (1) restoration is suboptimal in low-contrast regions where feature extraction is weaker, and (2) the purely synthetic SynDeepLesion training set fails to capture the full diversity of real implants, producing a domain gap on real-world CLINIC-metal data, where MARMamba (5-point radiologist score 3.748±1.271) slightly trails OSCNet+ (3.863±1.120). \
[[arXiv](https://arxiv.org/abs/2604.06622)] IEEE Transactions on Radiation and Plasma Medical Sciences, 2026. [[doi](https://doi.org/10.1109/TRPMS.2026.3674764)] [![Code](https://img.shields.io/badge/Code-purple.svg)](https://github.com/RICKand-MORTY/MARMamba)

 1. **NAFMAR: X-Ray CT Metal Artifact Reduction Using Neural Attenuation Field Prior** <img src="https://img.shields.io/badge/Self-Supervised-blue.svg" alt="Self-Supervised"> \
*J. Lee, S. Kim, J. Ahn, A. S. Wang, J. Baek* \
**Summary** \
NAFMAR is a self-supervised, per-case sinogram-domain inpainting method for CBCT metal artifact reduction that uses a Neural Attenuation Field (NAF) as a learned prior, removing the need for paired training data or any pretraining step. The NAF is an implicit neural representation that maps 3D spatial coordinates (after a multi-resolution hash encoding with a 2¹⁶-entry hash table and 4-dim features per level) through a compact MLP of 4 fully-connected ReLU layers with 64 channels each; the whole field has roughly 4.5 M trainable parameters (~17 MB). The pipeline has three stages per scan: (1) fit the NAF to the measured projections using Metal Trace-Masked Ray Sampling, which partitions rays into a non-metal set R_r and a metal-affected set R_m so that the metal-corrupted line integrals do not dominate fitting; (2) render a prior image from the optimized NAF and use it to inpaint the metal traces in the original sinogram; and (3) reconstruct the artifact-reduced volume with FBP. Optimization uses a two-term self-supervised loss L = L_RECON(θ, R_r) + λ_M · L_MA(θ, R_m) with λ_M = 1, where L_RECON is a squared-L2 fidelity on non-metal rays and L_MA is a weight-modulated squared-L2 on the metal-affected rays (w(r) attenuates their contribution). Optimization runs for 150 epochs (~77 K steps) per case on a single NVIDIA RTX 3090, taking roughly 15 minutes with ~4 GB of GPU memory. Experiments use dental CT volumes from TCIA with 2–5 manually inserted metal implants for the simulated study and the CLINIC-metal dataset (512×512×187 voxels) for the clinical evaluation; reconstructed CBCT volumes are 512×512×100 at 0.4×0.4×0.4 mm voxels. A CNN baseline (DSCMAR) is trained on 1,551 metal-free / metal-corrupted image pairs for comparison. With 4 metal implants, NAFMAR attains PSNR 34.42 dB / SSIM 0.931, versus DSCMAR (34.43 dB / 0.914) and CNNMAR (33.73 dB / 0.909), i.e. matching the supervised DSCMAR on PSNR while achieving the best SSIM among the compared methods. Total per-case inference is 7.2 s (0.6 s prior generation + 3.1 s sinogram inpainting + 3.5 s FBP). The authors note a primary limitation: the size of metal objects directly affects reconstruction quality—large metal implants produce large metal traces that compromise data fidelity during NAF fitting, so residual artifacts can persist in extreme cases involving large metallic objects. \
Medical Physics, 2025. [[doi](https://doi.org/10.1002/mp.17859)] [![Open Access](https://img.shields.io/badge/Open%20Access-brightgreen.svg)](https://pmc.ncbi.nlm.nih.gov/articles/PMC12257910/)

 1. **A Strategy for Simulation-Driven CT Metal Artifact Reduction Toward Improving Network Generalizability** <img src="https://img.shields.io/badge/Self-Supervised-blue.svg" alt="Self-Supervised"> \
*S. Yun, S. Hyun, D.-I. Choi, S. Cho* \
**Summary** \
This paper proposes a self-supervised framework for CT MAR that integrates physics-informed correction with generative deep learning, eliminating the need for real paired datasets. The method consists of two main components: (1) a lightweight multi-layer perceptron (MLP) that performs physics-driven polynomial beam-hardening correction with implicit sinogram consistency built into its optimization objective, enabling case-specific adaptation; and (2) a conditional latent diffusion model (LDM) trained to remove residual artifacts after MLP correction. A key innovation is the simulation strategy: the learned MLP parameters are reused to generate artifact-contaminated images from artifact-free scans, producing pseudo paired data that enables self-supervised training of the LDM without requiring real paired datasets. By operating in a low-dimensional latent space, the LDM significantly reduces inference time compared to pixel-space diffusion models. The method was evaluated on both the SynDeepLesion dataset and real clinical data, demonstrating superior artifact removal and structural preservation compared to state-of-the-art MAR techniques. The authors also won the AAPM CT-MAR Grand Challenge using a related approach. The framework specifically addresses limitations of existing DL-based MAR methods, which lack explicit physical modeling of artifact formation and rely heavily on data-driven mappings, making them prone to hallucination and anatomical distortion. \
Medical Physics, 2026. [[doi](https://doi.org/10.1002/mp.70336)]

 1. **PDuMSRNet: Prompt Guiding Multi-Scale Adaptive Sparse Representation-Driven Network for Low-Dose CT MAR** <img src="https://img.shields.io/badge/Supervised-blue.svg" alt="Supervised"> \
*B. Shi, B. Chen, S. Zhang, H. Fu, Z. Hu* \
**Summary** \
PDuMSRNet is a supervised, model-interpretable dual-domain framework that jointly addresses low-dose CT reconstruction and metal artifact reduction (LDMAR) using a single model across multiple dose levels. The image-domain backbone, PMSRNet, is inspired by multi-scale sparsifying frames and features a four-scale architecture (filter sizes 5×5 to 11×11, output channels 25–121). Two key modules drive the design: (1) a Prompt Guiding Scale-Adaptive Threshold Generator (PSATG) that fuses local (convolutional residual), regional (window attention), and global (anchored stripe attention) features together with a prompt comprising the dose level, metal mask, and input instance to produce scale-adaptive thresholds; and (2) a Multi-Scale Coefficient Fusion Module (MSFuM) based on double cross-attention that merges high- and low-resolution features across scales. PDuMSRNet unfolds T stages, each containing a sinogram-domain s̃-Net (three residual blocks) and an image-domain x-Net (PMSRNet). Training uses a hybrid loss combining weighted MSE (ω₁ = 0.01) in both image and sinogram domains with a multi-scale perceptual loss (ω₂ = 1×10⁻⁴) based on pre-trained ResNet-50. The model is trained on the DeepLesion dataset with 1,000 FDCT images × 80 metal masks (80,000 synthetic pairs, 416×416 images, 641×640 sinograms) for 100 epochs with batch size 1, and tested at 1/2, 1/4, and 1/8 dose levels (1×10⁵, 5×10⁴, 2.5×10⁴ incident photons at 120 kVp). PDuMSRNet outperforms 13 single-dose methods (FBP, REDCNN, InDuDoNet, DuMSRNet, CTformer, LIT-Former, etc.) and 3 multi-dose methods (AirNet, PromptIR, BDuMSRNet), achieving average PSNR/SSIM of 42.26/0.9771 (1/2 dose), 41.58/0.9742 (1/4 dose), and 40.44/0.9667 (1/8 dose). Storage is approximately one-third that of training separate DuMSRNet models per dose level. The authors note that the network occasionally fails to distinguish massive streaking artifacts from true anatomical tissue for large metal implants, and current methods exhibit blurring on clinical data due to domain gap between simulated training data and clinical test data. \
[[arXiv](https://arxiv.org/abs/2504.19687)] Medical Image Analysis, 2026. [[doi](https://doi.org/10.1016/j.media.2025.103870)] [![Code](https://img.shields.io/badge/Code-purple.svg)](https://github.com/shibaoshun/PDuMSRNet.git)

 1. **LDMNMAR: Metal Artifact Reduction Algorithm With Conditional Latent Diffusion Model for Dental Cone-Beam CT** <img src="https://img.shields.io/badge/Supervised-blue.svg" alt="Supervised"> \
*D.-I. Choi, S. Yun, S. Hyun, S. Cho* \
**Summary** \
LDMNMAR is a supervised metal artifact reduction method for dental CBCT that combines a conditional latent diffusion model (LDM) with an improved normalized metal artifact reduction (NMAR) pipeline. The method operates in multiple stages: first, a diffusion network trained in the latent space of a CVQ-VAE autoencoder estimates a clean image latent variable from noise, conditioned on the metal-artifact-corrupted image latent variables, to synthesize an artifact-corrected CBCT image. This LDM output then serves as a high-quality anatomical prior for a modified NMAR framework. The NMAR pipeline is augmented with a dedicated metal segmentation network and a secondary artifact correction network to suppress residual artifacts. The network is trained in a supervised manner on paired sets of metal-artifact-corrupted and clean reconstructed images using a combination of mean squared error (MSE) and learned perceptual image patch similarity (LPIPS) losses. Clinical dental CBCT projection data from 21 patients were used for evaluation on 512 × 512 images. Compared to CNNMAR, LDMNMAR improves RMSE from 34.78 × 10⁻⁴ to 19.30 × 10⁻⁴, PSNR from 49.3 to 54.3 dB, and SSIM from 91.2% to 97.2%. The total inference time for 350 images is approximately 202 seconds, including 109 s for LDM inference (0.314 s per image), 14 s for image tuning, 3 s for metal segmentation, and 74 s for reconstruction and NMAR. The authors note that diffusion model outputs inherently suffer from structural blurring (since inference is derived from noise) and are prone to hallucination errors—the modified NMAR step is specifically designed to mitigate these concerns. Additional challenges include the domain gap in CBCT data due to higher noise and scatter levels, as well as CBCT-specific artifacts such as cone-angle artifacts and limited field of view. \
Journal of Applied Clinical Medical Physics, 2025. [[doi](https://doi.org/10.1002/acm2.70317)] [![Open Access](https://img.shields.io/badge/Open%20Access-brightgreen.svg)](https://aapm.onlinelibrary.wiley.com/doi/10.1002/acm2.70317)

 1. **TDMAR-Net: A Frequency-Aware Tri-Domain Diffusion Network for CT Metal Artifact Reduction** <img src="https://img.shields.io/badge/Unsupervised-blue.svg" alt="Unsupervised"> \
*W. Chen, B. Ning, Z. Zhou, L. Shi, Q. Liu* \
**Summary** \
TDMAR-Net is an unsupervised diffusion model-based network that uniquely operates across three domains—projection (sinogram), image, and Fourier—to reduce metal artifacts in CT images. A high-pass filter module in the Fourier domain adjusts the weights of high-frequency and low-frequency components, while block-wise processing extracts diffusion priors that are iteratively introduced into the sinogram and image domains to fill metal-induced artifact regions. The framework employs a two-stage training strategy combining large-scale pretraining with masked data fine-tuning to enhance accuracy and adaptability. Validated on both synthetic and clinical datasets, TDMAR-Net demonstrates superior performance compared to existing unsupervised MAR methods. \
Physics in Medicine & Biology, 2025. [[doi](https://doi.org/10.1088/1361-6560/ae0efc)]

 1. **Bi-Constraints Diffusion: A Conditional Diffusion Model With Degradation Guidance for Metal Artifact Reduction** <img src="https://img.shields.io/badge/Unsupervised-blue.svg" alt="Unsupervised"> \
*M. Luo, N. Zhou, T. Wang, L. He, W. Wang, H. Chen, P. Liao, Y. Zhang* \
**Summary** \
BCDMAR is an unsupervised metal artifact reduction method that combines iterative reconstruction with a conditional score-based diffusion model. Unlike traditional approaches that use metal-excluded projection operators, BCDMAR introduces a metal artifact degradation operator in the data-fidelity term and employs a pre-corrected image as a prior constraint to guide the diffusion model's generation process, effectively preventing grayscale shifts and unreliable structures. By iteratively applying the score-based diffusion model and the data-fidelity step in each sampling iteration, the method maintains reliable tissue representation around metal regions while producing highly consistent structures in non-metal regions. Extensive experiments demonstrate BCDMAR's superior performance over state-of-the-art unsupervised methods (ADN, ACDNet) and supervised methods (DuDoNet, InDuDoNet+) both quantitatively and visually. \
IEEE Transactions on Medical Imaging, 2025. [[doi](https://doi.org/10.1109/TMI.2024.3442950)]

1. **Dual-Encoder Architecture for Metal Artifact Reduction in kV-Cone-Beam CT for Head and Neck Cancer Radiotherapy** <img src="https://img.shields.io/badge/Supervised-blue.svg" alt="Supervised"> \
*J. Ki, J. M. Lee, W. Lee, J. H. Kim, H. Jin, S. Jung, J. Lee* \
**Summary** \
This work targets metal artifacts in linear-accelerator-mounted kV-CBCT used for head-and-neck adaptive radiotherapy, where artifacts corrupt both the daily CBCT and, via deformable image registration (DIR), the synthetic planning CT that drives dose calculation. The authors argue that a single CNN must simultaneously (a) remove the streaks and (b) restore the corrupted anatomy, and that these two objectives pull in opposite directions for a single-encoder network. They therefore propose an image-domain dual-encoder U-shape network: Encoder1 is a UNet-style branch (convolutional blocks + max-pooling) tuned for aggressive artifact removal — max-pooling is well-suited here because metal-artifact pixels have anomalously high values — while Encoder2 is a modified FusionNet branch (residual convolutional blocks, strided convolutions instead of max-pooling) tuned for anatomy preservation. The decoder receives a convolutional feature from Encoder1 and an attentional feature from Encoder2, fused through a channel-wise attention block that sits on top of a spatial-attention-processed feature map; this "spatial + channel-wise attention" fusion is the proposed final model. For ablation the authors also build four single-encoder baselines (UNet, FusionNet, UNet/L, FusionNet/L where /L denotes a larger encoder that merges residual blocks / extra max-pooling / spatial attention) and two weaker dual-encoder variants (simple-addition fusion; spatial-attention-only fusion). Training is supervised with paired synthetic CBCTs generated from a CBCT dataset acquired on a Varian VitalBeam LINAC's C-arm CBCT at Seoul National University Hospital (2019–2020): 7 patients / 651 slices provide metal-artifact-free references, 24 patients / 2,232 slices provide metal-corrupted slices used only to extract realistic metal shapes (HU ≈ 8,000, erosion + Gaussian blur on the mask, small position perturbation), and the position-corrected metal is forward-projected via Radon transform, scaled to produce variable artifact strengths, and inverse-Radon-transformed into paired inputs/targets. The synthesized corpus totals 29,104 training / 3,795 validation / 7,201 simulated-test pairs, and a separate 34-patient / 3,155-slice real-world inference set is used for the clinical artifact-index evaluation. The supervised objective sums (i) pixel-wise MSE on the output, (ii) SSIM loss on the output, and (iii) an auxiliary MSE loss applied to intermediate Encoder2 features (convolved to image resolution) so that the over-preserving FusionNet branch is pushed to cleanly separate metal-artifact residual from anatomy. Training runs for 100 epochs with batch size 32 and random-crop augmentation; per-image inference time and specific GPU hardware are not reported in the manuscript. On the simulated test set, the proposed dual-encoder + spatial/channel attention achieves PSNR 41.86 dB, MSE 8.6×10⁻⁵, SSIM 0.9931, PCC 0.9937 — the best across all seven architectures: single UNet (41.00 / 1.07×10⁻⁴ / 0.9918 / 0.9927), single FusionNet (39.92 / 1.42×10⁻⁴ / 0.9903 / 0.9912), UNet/L (39.30 / 1.47×10⁻⁴ / 0.9903 / 0.9908), FusionNet/L (39.99 / 1.30×10⁻⁴ / 0.9910 / 0.9917), dual-encoder + simple-add (40.43 / 1.18×10⁻⁴ / 0.9915 / 0.9920), dual-encoder + spatial-attention only (40.73 / 1.13×10⁻⁴ / 0.9921 / 0.9924).
